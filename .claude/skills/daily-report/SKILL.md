# 工作日报整理

## 使用方式

直接运行脚本生成日报：

```bash
bash /root/.agents/skills/daily-report/scripts/daily_report.sh [范围]
```

## 支持的时间范围

| 参数 | 说明 |
|------|------|
| `today` | 今天 |
| `yesterday` | 昨天 |
| `week` | 本周一至今（默认） |
| `month` | 本月至今 |
| `YYYY-MM-DD` | 指定日期 |
| `YYYY-MM-DD..YYYY-MM-DD` | 日期区间 |

## 输出格式

脚本按日期分组展示提交记录，包含提交 hash、时间和提交信息（这是原始数据，供整理总结使用）：

```
时间范围: 2026-07-13 ~ 2026-07-15

## 2026-07-14（周二）

**`d0e5e488`** 09:54 [缺陷修复] 修复多线程日志重名覆盖问题

**`59e70361`** 09:54 [版本提测] 头文件和库文件提交

## 2026-07-15（周三）

**`60dad867`** 10:45 [新增需求] icns 模式下清空内置规则
```

## 总结输出要求（重要）

拿到脚本的提交列表后，**最终给用户的总结必须按日期（每天）组织**：每一天先列出日期标题，再概括当天完成的主要工作。**不要按主题/模块重新归类打乱日期顺序**。

整理要点：

- 以天为单位，对当天多次提交做归纳合并（同一主题的多次提交合并为一条）。
- 保留类型标签（如 `[新增需求]`、`[缺陷修复]`），让用户一眼看出当天工作性质。
- 语言精炼，提炼到「做了什么」，省略 hash 和具体时间（除非用户特别要求）。
- 无提交的日期直接跳过，不要列出空标题。

示例：

```
## 工作总结

### 2026-07-14（周二）
- [缺陷修复] 修复多线程日志重名覆盖问题，malicious 规则 NUMA 内存占用优化
- [脚本更新] 黑名单话单从 evilblock 调整到 malscan 输出
- [版本提测] 提交头文件和库文件

### 2026-07-15（周三）
- [新增需求] InduNetSecRx 新增 XSA 指令规则下发与热加载验证功能
- [新增需求] icns 模式下清空内置恶意报文/文件规则，修复 config_set 路径判断
- [新增需求] 探针接口程序纳入 ICE 打包和 icns 进程守护
```

## 注意事项

- 脚本默认只查询当前 Git 用户的提交
- 可通过环境变量 `GIT_AUTHOR` 指定查询的作者
- 确保在 Git 仓库目录下执行
